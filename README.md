# What is this?

- **This is a public database of free offers, student discounts and live coupon codes relevant to people living, working or studying in the UAE.**
- **Beginner-friendly repository for starting your open-source contribution journey.**
- **Feel free to add more if we missed anything!**
- **CONTRIBUTORS NEEDED FOR MAINTAINING THIS DATABASE!**

---

# How to contribute in this repository?

1. **Add a Star to this repository.**
2. **Fork the repo.**
3. **`git clone` the repo.**
4. **Open `database.md` from the `Database` folder.**
5. **Add/Modify/Replace data and files to contribute.**
6. **Create your Pull Request!**
7. **Explain what you have done in the description.**

---

# What contributions are accepted?

1. **Any spelling errors in the list of offers**
2. **Adding more offers which are not present**
3. **Adding genuine information about any listed offers**
4. **Fixing any broken links**
5. **If any offer links are not working anymore, mark it for renewal**
6. **If a link is not working, update it**
7. **Mention the duration/validity of an offer**

# FAQ?

- **I am just a visitor, should I contribute?**
  * Definitely — if you're visiting the link and find any information wrong, create a pull request fixing it.
- **I'm just a beginner, how difficult is this?**
  * Completely beginner-friendly if you follow the instructions in [`instructions/`](instructions/).
- **I don't want to contribute but I found something wrong in the list. What should I do?**
  * Open an Issue and a maintainer will fix it.
- **Why should I contribute?**
  * Contributing to open source helps you improve your own skills and helps others.
- **How can I be in the contributors list?**
  * Create a pull request, wait for it to get accepted, and you'll be listed automatically.
