## What is this?

- A public, community-maintained database of free offers, student discounts and coupons relevant to people living, working or studying in the UAE.
- Structured the same way GitHub's own resource lists are (data separated into `Database/`, contribution rules in `CONTRIBUTING.md`) so it survives as a living project instead of a blog post that goes stale.
- Curated and kept current by [GrabOn UAE](https://grabonuae.ae/), with the community fixing broken links and adding new offers via PRs.

## How to contribute

1. **Star this repo** ⭐ — it's how new contributors discover it.
2. **Fork** the repo.
3. `git clone` your fork.
4. Open [`Database/database.md`](Database/database.md).
5. Add / modify / replace a row to contribute.
6. Open a **Pull Request** and explain what you changed.

See [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`instructions/`](instructions/) for the exact format.

---

## What contributions are accepted?

1. Spelling/formatting fixes in the offers list
2. Adding a genuine offer that isn't listed yet
3. Correcting inaccurate offer info
4. Fixing broken or expired links
5. Flagging (via Issue) an offer that needs re-verification
6. Noting the duration/validity of an offer

## FAQ

**I'm just a visitor, should I contribute?**
Yes — if you spot something wrong, open a PR or an Issue.

**I'm a beginner, is this hard?**
No. It's one Markdown table. If you can edit a text file, you can contribute — see [`instructions/`](instructions/).

**Who maintains this?**
[GrabOn UAE](https://grabonuae.ae/) maintains and reviews contributions; anyone can submit a PR.

**Does Hacktoberfest count this repo?**
Yes, once tagged with the `hacktoberfest` topic.
