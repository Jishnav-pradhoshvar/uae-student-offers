# Contributing

Thanks for helping keep this list accurate.

1. Fork the repo and clone it locally.
2. Edit [`Database/database.md`](Database/database.md) only — don't restructure the tables.
3. One offer per PR is fine; batching several fixes in one PR is also fine.
4. Use the exact row format:
   ```
   | [OFFER NAME](https://link) | One-line benefit | Category |
   ```
5. Verify the link actually works and the offer is currently live before submitting.
6. Open the PR with a short description: what you added/fixed and why.

See [`instructions/`](instructions/) for step-by-step guides with examples.

Please don't submit:
- Offers that require payment to "unlock" the discount (affiliate traps)
- Duplicate entries
- Broken or placeholder links

Maintainers review PRs on a rolling basis. Please also read our [Code of Conduct](CODE_OF_CONDUCT.md).
