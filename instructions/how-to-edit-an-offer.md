# How to Edit or Fix an Existing Offer

Use this when a link is dead, an offer expired, or the details changed.

1. Open [`Database/database.md`](../Database/database.md).
2. Find the row for the offer.
3. Either:
   - **Fix the link** — replace the URL in the `[NAME](URL)` part.
   - **Update the benefit text** — edit the middle column.
   - **Remove the row entirely** — if the offer is permanently gone, delete the whole line rather than leaving a dead entry.
4. Open a Pull Request explaining what changed and why (e.g. "Emirates changed their student discount terms — updated benefit %").

If you don't want to submit a PR yourself, open an **Issue** instead and a maintainer will fix it.
